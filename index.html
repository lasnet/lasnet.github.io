WAZUH / SIEM
01SIEM · Detection · Automation

Wazuh SIEM implementation and development

A centralized event collection and analysis system for a heterogeneous infrastructure, with custom detection rules, alerts and automated reporting.

View case details

Challenge

Deploy Wazuh, connect infrastructure and security systems, then implement event processing, detection, reporting and notification scenarios.

Implementation

Deployed Wazuh components and Windows/Linux agents. Connected MikroTik, Check Point, Cisco, Cyber Protego DLP, Kaspersky, OpenAppSec WAF, Nginx, Postfix and 1C logs. Built a ClickHouse-to-Wazuh pipeline with Python and Airflow, plus custom decoders and rules.

Result

Centralized visibility across disparate sources, actionable detection scenarios, automated notifications and reporting, and role-based access through Keycloak.

CHECK POINT / NETWORK
02Firewall · Segmentation · High availability

Check Point infrastructure and network segmentation

A resilient security perimeter with three-tier segmentation, controlled inter-segment traffic and policies aligned with business processes.

View case details

Challenge

Deploy and maintain a highly available Check Point infrastructure, segment the network and ensure stable operation of its protection components.

Implementation

Built gateway clusters and the Security Management Server, developed firewall policies and configured HTTPS Inspection, Content Awareness, Threat Prevention, Anti-Virus, Threat Emulation and IPS. Designed DMZ, APP and DB segments with controlled access rules.

Result

A manageable, resilient perimeter that separates critical systems, limits traffic between tiers and supports reliable troubleshooting across network, policy and protection layers.
