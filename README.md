# Levin Aleksandr — Cybersecurity Portfolio

Personal cybersecurity portfolio published with GitHub Pages. The site presents services, skills and practical case studies in English and Russian.

Published site: <https://lasnet.github.io/>

## Technology

Static HTML, CSS and vanilla JavaScript. There is no build step or backend.

## Local preview

Run a static server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` — page structure and English content
- `assets/style.css` — visual design and responsive layout
- `assets/script.js` — language switch, navigation and contact form behavior
- `assets/favicon.svg` — site icon

GitHub Pages publishes the repository content directly. Replace the placeholder email, GitHub and Telegram links in `index.html` before using the contact section publicly.
